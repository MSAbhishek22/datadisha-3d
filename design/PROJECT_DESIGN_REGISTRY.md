# Project Design Registry — DataDisha 3D vs the fleet

Per ABHI_22 Blueprint Part V: a new project must differ from the three most
recent in more than accent colour.

| Axis | Night Touge (Nov 2026) | TriageMate (Nov 2026) | SecretGate (Nov 2026) | **DataDisha 3D** |
|---|---|---|---|---|
| Metaphor | A windscreen at 2 a.m. | The triage desk (editorial desk) | A security ledger / vault | **A surveyor's chart table** |
| Theme | Dark (deep blue night) | Light editorial | Dark, security-room | **Light, warm paper** |
| Accent | Amber sodium light | Editorial ink + one link colour | Red/amber alert tones | **Terracotta + deep teal data ramps** |
| Display type | Monospace instruments | Serif headlines, light | Mono + condensed | **Georgia serif report voice, tabular data figures** |
| Layout | Full-screen game canvas | Document column | App panel in Jira | **Three flat chapters: problem → explorer → outcome** |
| 3D treatment | Full driving scene | None (2D) | 3D exposure graph (nodes) | **Instanced block map: height + colour both carry data** |
| Interaction model | Keyboard driving | Forms + lists | Issue-panel actions | **Direct manipulation: hover, click, compare two blocks** |
| Motion | Speed, FOV kick | Quiet fades | Graph physics | **Slow 600 ms grow/recolour; one opening camera move** |

Distinct on every axis from the three most recent projects. The closest
neighbour is TriageMate (also light), but its metaphor (a desk of paper
tickets), layout (document column) and interaction (forms and filters) are
all different from a chart table you orbit.
